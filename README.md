# Holiday cost comparison, August 2027

A single-page website comparing holiday options per family for 1 to 14 August 2027.

- `index.html` is the whole site. There is nothing to build or install.
- To publish with GitHub Pages: Settings, Pages, Source "Deploy from a branch", Branch `main`, folder `/ (root)`.
- To update the numbers, upload a new `index.html` with the same name.
